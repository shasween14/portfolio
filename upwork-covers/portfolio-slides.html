Upwork Portfolio Slides — extra images per project

Each slide is exactly 1024×768, in the same style as your existing thumbnails, and exports at 2× for a sharp upload. Add them to the same Upwork portfolio item as extra images: the title card stays as image 1, these become images 2, 3, 4… so a client opening the item sees the architecture, the real numbers and the hard problems instead of just a title.
No client names, no logos, no URLs and no credentials appear on any slide.
