Annotated screenshots — QParking Local Server (Electron gate controller)

Captures of the running desktop app on a bench: its own Electron main process, its own SQLite database and its own gate state machine, driven through the same window.bridge calls the UI uses and the real /lpr/event webhook. The qparking SaaS and the Touch’n’Go W4G payment device are stubbed, because neither is on this machine — see tools/qparking-local/README.md. Rendered to upwork-covers/qparking-local/.
