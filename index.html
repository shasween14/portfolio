Full-stack commerce & POS platform · Lead developer
Lead · 1,533 commits

A complete, Docker-powered commerce platform with multiple front-end applications (POS, Kiosk, Tablet, Web) backed by a Laravel API and a production-like 9-service infrastructure stack — all orchestrated to run with a single command.

  • Architected a Laravel REST API with PostgreSQL, Redis, queues and Reverb websockets for real-time updates

QParking Cloud 2.0 — Multi-Site Parking SaaS

Multi-portal parking management platform · Core / lead developer
Lead · 472 commits

A multi-site parking management SaaS with three role-based portals — HQ Admin, Site Operator and Customer — covering live occupancy, automated LPR gate control, season passes, billing and GreenParking/ESG rewards, deployed across local, staging and production Docker environments.

  • Laravel 13 REST API (Sanctum auth, Spatie roles) backed by MySQL, with a React 18 + TypeScript + Vite front-end shared across three portals
  • Integrated a vendor LPR camera SDK and TCP-driven barrier/kiosk hardware for automated vehicle entry, exit and gate control
  • Designed a customer/vehicle/pass/bay domain model — passes cover a pool of plates but admission is capped by bays, not plate count — shared between the cloud platform and the on-prem gate controller so the two never drift
  • Modeled an 18-table schema spanning sites, vehicles, season passes, invoices, rate policies, promotions and wallets
  • Layered Docker Compose overlays (local dev server, staging, production) on one base file, with a scripted deploy.sh handling DB backups, pulls and rebuilds
